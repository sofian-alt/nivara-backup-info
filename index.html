NIVARA CONTROL Backup

Perlindungan salinan data PT Nivara Meditech Indonesia melalui backup terenkripsi dan pemeriksaan pemulihan.

Fungsi aplikasi

Aplikasi membantu operator yang berwenang menyalin database dan file perusahaan, mengenkripsi paket sebelum dikirim ke Google Drive, serta memeriksa checksum dan kemampuan pemulihannya.

Backup disimpan sebagai dua salinan yang dimiliki akun Google berbeda. Aplikasi meminta akses hanya ke file Google Drive tertentu yang dibuat atau digunakan dengan aplikasi ini, bukan akses seluruh isi Drive.

Status layanan

Otomatisasi harian masih dalam persiapan dan verifikasi. Keberhasilan koneksi Google atau uji file sintetis tidak berarti backup keuangan terbaru telah selesai. Waktu snapshot dan hasil pemulihan harus diperiksa pada laporan backup.

Untuk pengguna berwenang

Aplikasi ini digunakan secara internal oleh pemilik dan operator perusahaan. Halaman ini tidak menyediakan akses ke ERP, file backup, kunci pemulihan, atau transaksi perusahaan.
