Kebijakan privasi

Informasi penggunaan data Google oleh aplikasi backup internal PT Nivara Meditech Indonesia.

Data dan izin yang digunakan

Aplikasi menggunakan alamat email dan identitas login Google untuk memastikan akun yang terhubung merupakan akun yang diizinkan owner. Aplikasi membaca kapasitas penyimpanan, serta membuat, membaca dan mengelola file atau folder tertentu yang digunakan aplikasi melalui izin drive.file.

Izin tersebut mencakup kemampuan mengubah dan menghapus file aplikasi. Namun, alur backup yang disiapkan tidak menghapus salinan backup lama secara otomatis. Aplikasi tidak meminta akses ke seluruh Drive, email Gmail, kontak, atau kalender.

Tujuan pemrosesan

Data digunakan untuk memeriksa identitas akun dan kuota, menyimpan paket backup terenkripsi, mengunduhnya kembali untuk pemeriksaan integritas, serta mencatat status teknis. Data Google tidak dijual atau digunakan oleh aplikasi ini untuk iklan maupun pelatihan model AI.

Penyimpanan dan penyedia layanan

Paket dienkripsi sebelum dikirim ke Google Drive. Google menyediakan penyimpanan cloud dan autentikasi. Lingkungan operator atau runner yang disetujui memproses data sementara untuk membuat atau menguji backup; apabila GitHub Actions diaktifkan, GitHub menyediakan lingkungan komputasinya.

Credential akses disimpan secara privat dan tidak dimasukkan ke source code atau log. Kunci pembuka backup permanen disimpan terpisah dari backup dan tidak diberikan kepada runner CI. Kit pemulihan pada cloud harus dienkripsi secara terpisah. Perlindungan tersebut tetap memerlukan pengujian pemulihan dan akses owner yang berhasil; tidak diasumsikan lengkap hanya karena koneksi tersimpan.

Akses manusia dan laporan

Akses operasional dibatasi pada owner dan operator yang diberi wewenang. Laporan teknis dapat memuat waktu, jumlah objek, checksum dan hasil pemeriksaan, tanpa mencantumkan credential, kunci pembuka atau isi transaksi. Pemulihan atau pemeriksaan yang memerlukan isi data dilakukan hanya sesuai otorisasi owner.

Retensi dan pencabutan akses

Salinan lama dipertahankan sampai owner menentukan kebijakan retensi dan menyetujui penghapusan. Pengguna dapat mencabut koneksi melalui pengaturan Akun Google. Pencabutan menghentikan akses baru aplikasi, tetapi tidak otomatis menghapus file yang sudah dimiliki pengguna di Drive.

Untuk permintaan akses atau penghapusan, hubungi sofian@nivarameditech.com. Penghapusan file backup harus mempertimbangkan kebutuhan pemulihan dan kewajiban perusahaan.
